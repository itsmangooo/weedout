# Weedout for VS Code

Open a repository and keep coding. Weedout watches supported dependency files and
`.weedout.yml`, debounces changes, scans automatically, and keeps editor diagnostics,
inline fix hints, hover context, and the Weedout Findings view in sync.

The only commands are account and project lifecycle actions:

- `Weedout: Auth`
- `Weedout: Rules`
- `Weedout: Create Project`
- `Weedout: Delete Project`

There is deliberately no Scan, Refresh, Sync, or Link command.
